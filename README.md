
# Heart Disease Prediction Using Machine Learning

## Project Overview
Heart Disease Prediction is a Machine Learning-based web application designed to predict the possibility of heart disease using patient medical information.

The system analyzes various health parameters such as age, blood pressure, cholesterol levels, chest pain type, and ECG results to predict the risk of heart disease.

## Objectives
- To predict the possibility of heart disease using Machine Learning.
- To analyze patient health-related parameters.
- To support early identification of potential heart disease risks.

## Technologies Used
- Python
- Machine Learning
- Django
- HTML
- CSS
- SQLite

## Features
- User-friendly web interface.
- Patient health information input.
- Machine Learning-based prediction.
- Displays prediction results.

## Project Workflow
1. Collect patient health information.
2. Process the input data.
3. Apply the trained Machine Learning model.
4. Generate the prediction result.

## Applications
- Healthcare data analysis.
- Early risk identification.
- Machine Learning-based healthcare applications.

## Note
This project is developed for educational purposes and is not a substitute for professional medical diagnosis.
